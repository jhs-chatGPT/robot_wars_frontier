ROBOT WARS FRONTIER v0.8 P15 플레이용 패키지

실행
1. ZIP 전체 압축을 풉니다.
2. 압축을 푼 폴더의 index.html을 브라우저에서 엽니다.
3. assets 폴더를 index.html과 함께 유지합니다.

P14 세이브 이어하기
- 같은 브라우저와 같은 실행 주소/파일 경로를 유지하면 기존 저장 키로 불러옵니다.
- 가장 간단한 업데이트: P14 폴더를 백업한 뒤 기존 위치의 index.html을 P15 index.html로 교체합니다. 기존 assets는 동일합니다.
- 다른 폴더·브라우저·PC로 이동 시 로컬 저장소가 공유되지 않을 수 있습니다.
  P14 관리자 > 저장 데이터 > JSON 백업 다운로드로 백업한 다음,
  P15에서 임시 시작 후 저장 / 불러오기 > JSON 복원으로 가져옵니다.
  복원하면 현재 P15 데이터가 백업 내용으로 교체됩니다.
- P15는 원래 기체/무기 ID와 저장 키를 유지합니다. 기본 기체 밸런스만 새 수치로 적용됩니다.
- 실제 사용자 세이브를 제공받은 것은 아니며, P14 실행 코드로 만든 육성·개조·동료 포함 테스트 세이브로 검증했습니다.
