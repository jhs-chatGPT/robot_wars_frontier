# ROBOT WARS FRONTIER — React v0.9.10

기존 **v0.8 P15.6.23 안정화판**을 기준으로 React로 이전한 ROBOT WARS FRONTIER 프로젝트입니다. v0.9.10에서는 v0.9.9 HUD 적용 후 실제 1536×1024 화면에서 확인된 축소감·과도한 빈 공간·화면 간 밀도 불일치를 바로잡는 UI 안정화 핫픽스를 적용했습니다.

## v0.9.10 핵심 변경
- TOP HUD 신형 디자인 유지 + 높이/로고/자원 패널 비율 확대
- 좌측 메뉴 폭/행 높이/아이콘/글자 크기를 실사용 해상도에 맞게 재조정
- 홈 화면의 과도한 빈 공간을 줄이고 지휘관/주력기체/다음작전 중심 밀도로 재배치
- 파일럿 관리의 목록/정보/훈련 가독성 및 카드 밀도 확대
- 파일럿 능력치에서 `지휘` 삭제
- 현재 능력치: `격투 / 사격 / 반응 / 조종 / 방어 / 기량`
- `특수스킬` 표현을 `특수능력`으로 정리
- 특수능력은 `습득 / 강화` 모달 방식으로 변경
- 특수능력 Lv 데이터를 실제 전투 보정에서 읽도록 개선
- 기존 저장 데이터의 `command` 항목은 로드 시 자동 제거/정규화


### 전체 메뉴 UI 안정화
- 파일럿 영입 / 기체 목록 / 기체 개발 / 강화파츠 / 상점 / 도감 / PvP / 대회 / 관리자 / 설정 / 전투 / 작전 출격의 글자와 카드 밀도를 페이지별로 보정
- 기존 화면의 내부 기능 레이아웃은 유지하고 TOP/사이드바/패널 톤만 같은 FRONTIER HUD 계열로 통일
- 신규 안정화 CSS는 `data-page="..."` 범위로 한정해 다른 메뉴의 div에 영향을 주지 않도록 구성

## 저장 데이터 호환
React판은 `rwf-react-v0.9-save` 키로 자동 저장됩니다.
기존 P15.6.23 저장 데이터가 있고 React 저장 데이터가 없다면 다음 레거시 키를 자동 감지합니다.

- `robot_wars_proto_v8_ui_match`
- `robot_wars_proto_v8`
- `robot_wars_proto_v2`
- `robot_wars_proto_v1`

v0.9.9부터 예전 저장 데이터에 `stats.command`가 남아 있어도 로드 시 현재 6능력 구조로 자동 정규화합니다.

## 실행
```bash
npm install
npm run dev
```

## 프로덕션 빌드
```bash
npm run build
```

빌드 결과는 `dist/`에 생성됩니다.

## Netlify
`netlify.toml` 설정:
- Build command: `npm run build`
- Publish directory: `dist`
- SPA fallback: `/* -> /index.html`

GitHub 저장소 루트에 프로젝트 파일을 그대로 업로드하면 Netlify Git 배포에 사용할 수 있습니다.

## 검증
현재 런타임에는 `node_modules`가 없어 실제 Vite production build는 실행하지 못했습니다. 대신 전체 TypeScript 소스 구문 검사, 임시 React/Zustand 타입 선언을 이용한 전체 `src` 의미 검사, CSS 괄호 검사, `/assets` 참조 누락 검사를 수행했고 v0.9.10 변경으로 인한 코드 오류는 발견되지 않았습니다.

자세한 내용은 `FINAL_VALIDATION.md`를 참고하세요.
