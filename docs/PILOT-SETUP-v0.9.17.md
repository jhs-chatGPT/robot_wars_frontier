# v0.9.17 파일럿 등록 흐름 개편

## 변경 요약

기존 React 등록 흐름의 `파일럿 선택 → 계통 선택 → 기체 선택` 3단계를 아래 2단계로 통합했습니다.

1. 파일럿 선택 · 정보 수정
2. 기체 선택

## 파일럿 선택 · 정보 수정

- 좌측: 파일럿 목록
- 중앙: 선택 파일럿의 초상화 + 전신 이미지 + 기본 프로필
- 우측: 사용자 수정 영역
  - 성 / 이름 개별 입력
  - 생년 / 월 / 일 선택
  - 혈액형 A / B / O / AB 버튼 선택
  - 리얼계 / 슈퍼계 선택
- 능력치와 정신 커맨드 목록은 이 화면에 직접 표시하지 않음
- 별도 계통 선택 화면 삭제

## 정신 커맨드 계산

`생년월일 + 혈액형 + 계통` 조합으로 정신 커맨드를 내부 계산합니다.
현재 전투 엔진이 지원하는 정신 커맨드 범위 안에서 조합이 결정되며, 등록 완료 시 PlayerPilot 데이터에 저장됩니다.

## 기체 선택

선택한 계통에 맞는 초기 기체 후보만 표시합니다.

- 리얼계: 리얼계 starterUnitIds
- 슈퍼계: 슈퍼계 starterUnitIds

최종 등록 시 사용자 수정 이름, 생년월일, 혈액형, 계통, 계산된 정신 커맨드, 선택 기체를 함께 저장합니다.
