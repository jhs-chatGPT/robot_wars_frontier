## 데이터/동작

파일럿 관리, 기체 상세, 작전 준비,6개 바로가기, 공지 dialog,일일 보상 수령은 기존 store/이동 함수를 사용한다. 이벤트 실제 일정이 없으므로 준비 중/기간 미정 유지. 배너1개에 맞춰 전환 버튼은 disabled,01/01 표시. 실제 이벤트 추가 시에만 전환을 활성화한다. 저장/전투/보상 로직은 이 패치에서 수정하지 않았다.

## 검증과 제한

전체 시안은 ImageGen으로 생성한 시각 참고안이며 실행 캡처가 아니다. 생성된 미리보기1672×941, React 설계 기준1920×1080. 실제 코드에는 파일럿 관리 버튼,작전 설명,1/1 이벤트 상태를 포함하며 생성 이미지가 코드 모든 세부를 보증하지 않는다.

일일 임무 테스트4개 통과. npm run build는 tsc 미설치로 중단. 브라우저 실행 파일 및 Cloud Browser/Sites가 없어 화면 캡처/시각 QA/클릭 회귀검증은 blocked. 따라서 배포 완료 또는 목표와 일치 검증 완료로 보지 않는다. npm install 후 npm run build,1920×1080 HOME 캡처로 최종 검증 필요.

패치 ZIP은 v0.9.14 전체본 위에 같은 경로로 덮어쓴다. 전체 ZIP은 별도 전체 소스다. 공개 사이트에는 배포하지 않았다.
