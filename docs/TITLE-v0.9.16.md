# 시작 화면 v0.9.16

기준 프로젝트: robot_wars_frontier_v0.9.15_home_full.zip

## 적용 내용
- 제공된 두 번째 배경(02-9292.png)을 public/ui/title-background.png로 바이트 변경 없이 복사.
- 1920×1080 기준 X=1060, Y=600, 버튼 340×56, 간격 14.
- 16:9 전체 화면을 균일 축소하며 다른 비율에서는 여백을 둬 배경 크롭 방지.
- 시작 / 이어하기 / 파일럿 도감 / 설정. 시작 기본 강조.
- 선택, hover, focus-visible, 눌림 상태 및 방향키/Home/End 탐색.
- 저장이 없으면 이어하기 비활성화. 기존 저장 데이터와 새 게임 흐름 유지.
- 파일럿 도감은 등록 없이 열람 가능. 설정은 기존 설정 컴포넌트 재사용.
- 다른 게임 화면은 변경하지 않음.

## 확인
배경 SHA-256 및 바이트 일치 확인. 네 메뉴와 기존 진입/등록 경로 연결 정적 확인.
npm install은 registry.npmjs.org 403으로 차단되어 TypeScript/Vite 빌드 및 브라우저 실행 검증은 미완료.

## 적용
패치 ZIP을 기존 v0.9.15 프로젝트 루트에 덮어쓰거나 전체 ZIP 사용.
의존성 설치가 가능한 환경에서 npm install && npm run build 실행.
